# Portfolio — Ivo Gioffre


#  Introducción

Este proyecto consiste en un portfolio web personal diseñado para mostrar de una manera organizada y visual diferentes aspectos de mi formación en el área de Computación, incluyendo mis habilidades técnicas, proyectos realizados y medios de contacto.

Para el diseño se buscó una estética neon inspirada en el estilo retro de los años 80, utilizando colores brillantes como rosa, celeste, violeta y amarillo sobre fondos oscuros. La estética está inspirada principalmente en el proyecto de Nickify buscando mantener una identidad visual similar entre ambos.



#  Tecnologías utilizadas

- HTML

HTML se utilizo para construir la estructura y el contenido de la página
Define elementos como:
- Navbar
- Secciones
- Títulos y textos
- Tarjetas de proyectos
- Formulario de contacto
- Footer
- Modales
También permite conectar las diferentes partes del portfolio mediante enlaces e IDs.


- CSS

CSS se utilizó para definir prácticamente toda la apariencia visual del portfolio.
Se encargó de:
- Colores
- Tipografías
- Fondos
- Degradados
- Bordes
- Sombras neon
- Animaciones
- Distribución de los elementos
- Modo oscuro y claro
Gran parte importante del diseño está basada en CSS como el sol retro,la grilla en perspectiva y diferentes efectos de iluminación.



- Bootstrap

Bootstrap se utilizó como un complementario para facilitar la construcción de diferentes partes de la página.
Se utilizaron sus clases y componentes para:

- Crear el sistema de navegación.
- Hacer que la navbar sea responsive.
- Crear el menú desplegable en dispositivos pequeños.
- Utilizar botones y utilidades de espaciado.
- Crear los modales de los proyectos.
- Adaptar diferentes elementos a distintos tamaños de pantalla.

El diseño visual principal no depende exclusivamente de Bootstrap, ya que gran parte de la estética neon y los estilos personalizados fueron desarrollados mediante CSS 



- GitHub Pages
El portfolio fue preparado para poder publicarse utilizando GitHub Pages
GitHub Pages permite alojar una página web directamente desde un repositorio de GitHub, haciendo que el portfolio pueda ser accesible mediante una dirección web sin necesidad de contratar un servidor.
La estructura del proyecto permite que GitHub Pages cargue el archivo index.html como página principal y utilice los archivos CSS, JavaScript, imágenes y demás recursos del proyecto.


# Estructura:

- index.html
Contiene la estructura y el contenido principal del portfolio.

- styles.css
Contiene los estilos personalizados, la estética neon, animaciones y modo claro/oscuro.

- script.js
Contiene las funcionalidades dinámicas básicas del portfolio.

- Carpeta img
Contiene las imágenes utilizadas para representar los diferentes proyectos.

- CV

Contiene el currículum de caracter decorativo.

Todos los datos fueron revisados en el W3C Validator
